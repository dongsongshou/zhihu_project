# 知乎同频观点匹配系统

基于 Streamlit 构建的知乎内容主题匹配与讨论关系探索系统，覆盖“内容采集 - 文本清洗 - 特征提取 - 用户画像 - 多信号匹配 - 过程解释 - 群体分析 - 报告输出”的完整链路。系统输出的是公开内容的主题相关性，不等同于真实立场、身份认证或互动成功率。

## 项目结构
```text
知乎同频观点匹配系统/
├── home.py                  # 项目首页与状态总览
├── pages/
│   ├── 1_用户画像解析.py      # 生成用户画像并加入候选池
│   ├── 2_同频匹配引擎.py      # 计算基准用户与候选池的相似度
│   ├── 3_讨论AI催化剂.py      # 群体统计分析
│   └── 4_Agent对话仿真厅.py   # 群体观点报告输出
├── utils/
│   ├── match_engine.py        # 聚类与匹配辅助逻辑
│   ├── zhihu_openapi.py       # 知乎搜索、主题词和画像生成
│   ├── content_match.py       # TF-IDF 内容匹配核心算法
│   ├── visual_helper.py       # 雷达图、热力图工具
│   └── config.py               # 环境配置
└── README.md
```

## 功能概览
- 用户画像构建：根据输入关键词生成 8 维观点画像。
- 内容驱动匹配：对搜索摘要进行 TF-IDF 特征提取，计算正文余弦相似度，并与 8 维主题余弦融合。
- 群体分析：汇总匹配结果，输出基础统计与群体画像。
- 报告输出：生成结构化结果，支持后续扩展为导出或下载。

## 流程说明
1. 在“用户画像解析”页面输入关键词，生成画像并加入候选池。
2. 在“同频匹配引擎”页面选择基准用户并执行匹配计算。
3. 在“讨论AI催化剂”页面查看群体统计结果并生成分析数据。
4. 在“Agent对话仿真厅”页面生成最终报告并预览结果。

## 算法执行过程与依据

### 1. 内容采集

`zhihu_search()` 接收关键词并请求知乎搜索接口，保留标题、摘要和原始条目。成功时标记 `is_real_search=True`；接口无结果或不可用时使用输入文本兜底，并明确标记来源，避免把模拟数据误称为真实数据。

### 2. 文本清洗

`clean_content()` 依次进行 HTML 实体解码、标签清除、空白归一化、按行去重，并限制单个对象最多处理 30,000 字符。这样可以降低网页格式和重复摘要对结果的影响，同时不主动删除观点词。

### 3. 特征提取

`content_features()` 对中文提取连续 2、3、4 字片段，对英文提取完整单词。中文通常没有空格，字符 n-gram 不依赖额外分词器；英文保留单词有利于跨语言关键词匹配。字符片段可能重叠，因此页面将其称为“共同文本特征”，不把它们直接解释成独立观点证据。

### 4. TF-IDF 建模

对候选池建立统一特征矩阵。TF-IDF 通过降低候选池中普遍出现的词、提高区分度高的词来减少热门词的过度影响；`sublinear_tf=True` 使用对数词频，避免同一词重复出现完全主导结果；`norm="l2"` 便于用向量内积计算余弦相似度。为控制交互成本，最多保留 12,000 个特征。

### 5. 正文相似度

基准文本向量为 x，候选文本向量为 y：

`S_text = (x · y) / (||x|| ||y||)`

页面还计算每个共同特征的贡献：`TFIDF_i(x) × TFIDF_i(y)`。所有共同特征贡献之和等于正文余弦，页面展示贡献最高的 12 项，从而解释“为什么被推荐”。

### 6. 8 维主题向量

`build_semantic_embedding()` 根据主题词表统计内容命中，形成 8 维主题向量：科技发展乐观、社会公平、文化包容、风险审慎、个人/集体、现实务实、创新接纳、公共参与。向量 L2 归一化后计算主题余弦：

`S_topic = (a · b) / (||a|| ||b||)`

该模块提供稳定、可解释的主题信号，但不是训练型立场识别模型。

### 7. 多信号融合

最终匹配分数为：

`S_final = α × S_text + (1 - α) × S_topic`

其中 α 是页面可调的正文权重，默认 0.8。正文承载更具体的语境，主题向量提供更稳定的宏观结构；主题向量不可用时自动退化为正文分数。结果按综合分降序排序，同分按候选索引稳定排序。

### 8. 匹配过程可视化

页面按“搜索摘要 → 清洗 → 中文片段/英文单词 → TF-IDF → 正文余弦 → 主题余弦 → 权重融合 → 排序”展示流程，并提供对象数量、特征数量、正文/主题贡献柱状图、共同特征贡献图和原始摘要核对区。可下载 CSV 结果。

### 9. MMR 多样化推荐

主题探索工作台采用 MMR，避免推荐对象全部来自同一个主题：

`MMR(i) = λ × S(base,i) - (1-λ) × max(S(i,j))`

第一项鼓励与基准相关，第二项惩罚与已选对象重复。λ 越高越偏同频，越低越偏主题多样性。该方法是可解释的启发式排序，不是成功率预测。

### 10. 群体统计和报告

系统对匹配成员的主题分数求均值，统计成员数、相似度区间、数据来源质量，并导出 JSON/Markdown。报告明确保留分析边界：主题分布不等于真实立场；搜索结果不等于用户身份验证；匹配分数不等于互动成功概率。

## 数据结构

画像核心字段包括 `input_text`、`search_content`、`embedding`、`is_real_search`、`viewpoint_scores`、`viewpoint_names` 和 `raw_items`。内容匹配结果额外包含 `text_similarity`、`topic_similarity`、`text_weight`、`shared_features` 和 `evidence`，保证结果可追溯。

## 评估与后续升级

当前尚未使用人工标注数据集校准参数，建议后续用 Precision@K、Recall@K、NDCG@K 和人工“适合讨论”评分评估。升级路线包括：授权范围内的用户内容接口、句向量与 TF-IDF 双通道、支持/反对/中立方向识别、人工标注排序模型、来源审计和隐私保护。
