## ✨ 项目亮点与创新点
1. **8维观点向量建模**
不依赖简单标签，从用户回答文本抽取「教育观、AI认知、社区文化、思辨态度、实践倾向、情绪倾向、包容度、批判倾向」8维观点向量，刻画用户深层思想立场。

2. **多策略智能匹配算法**
- ✨灵魂同频：寻找高共识、思想共鸣的交流伙伴
- 🔍互补视角：立场适度差异，互相启发学习
- ⚡观点碰撞：打破信息茧房，接触异见

融合**余弦相似度+欧式距离**，量化输出**共识度 / 冲突度**双指标。

3. **社区群体挖掘：KMeans用户聚类**
自动对社区用户观点向量聚类，划分不同思想圈层；提供相似度热力图、交互式社交网络图，直观观察群体结构。

4. **AI社交破冰催化剂**
多风格生成适配话题、开场破冰话术、高风险话题避雷清单，降低线上沟通门槛。

5. **Agent数字分身对话仿真 + 智能复盘**
模拟两位用户真实对话氛围，可调节沟通包容度；自动复盘对话风险与沟通建议，**在真实交流前预判冲突风险**。

6. **高鲁棒工程设计**
完整异常捕获、API调用失败自动降级Mock演示模式；无需密钥即可完整体验全部功能；会话状态持久，页面切换数据不丢失。

## 🚀 快速运行
### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 两种运行模式
#### 🎮 演示模式（开箱即用，不需要API Key）
直接启动，全部功能使用模拟Mock数据：
```bash
streamlit run Home.py
```

#### 🔑 真实API模式（可选）
在项目根目录新建 `.env` 文件填入接口地址与密钥：
```env
ZHIHU_AGENT_BASE_URL=https://api.zhihu.com/v1
ZHIHU_AGENT_API_KEY=你的密钥
```
启动项目后自动切换真实大模型调用，解析真实文本。

访问地址默认：`http://localhost:8501`

## 📋 使用流程
1. **首页**：查看社区全局大盘，用户聚类分布、相似度热力图、交互式社交网络图谱。
2. **1‑用户画像解析**：输入用户ID解析基准用户画像；也可以自定义文本新增模拟用户扩充社区样本。
3. **2‑同频匹配引擎**：选择匹配策略，批量计算候选用户；查看匹配榜单、共识/冲突指标、雷达向量对比。
4. **3‑讨论AI催化剂**：选择匹配对象，生成多风格破冰话术、推荐话题、需要规避的风险话题。
5. **4‑Agent对话仿真厅**：调节沟通包容度，启动数字分身对话预演，获取AI沟通复盘建议。

## 🧮 核心算法说明
1. **融合相似度计算**
> `score = cosine_similarity(vec_a, vec_b) − 0.1 * euclidean_distance(vec_a, vec_b)`
融合余弦相似度（方向：观点立场）与欧式距离（向量幅值差异），获得更鲁棒的观点接近程度。

2. **共识度 & 冲突度**
```
consensus = round((similarity + 1) / 2 * 100, 1)
conflict = 100 − consensus
```

3. **KMeans观点聚类**
对全体用户8维观点向量做无监督聚类，自动划分社区思想群体，用于社区圈层分析。

4. **三种匹配权重策略**
- 灵魂同频：直接使用融合相似度作为排序权重
- 互补视角：优先选择相似度接近0.5，既有共识又有差异
- 观点碰撞：取相似度反向，优先立场差异大的对象
